# Hallazgos

Los estados describen el contraste entre el diagnóstico del plan y los archivos locales. `Confirmado` = evidencia en el código o prueba indicada; `Descartado` = formulación del diagnóstico no coincide con el código; `Nuevo` = evidencia adicional surgida de la revisión. Severidad orientativa: crítica / alta / media / baja; no es una calificación de cumplimiento completa.
